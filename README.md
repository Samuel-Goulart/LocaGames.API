API RESTful desenvolvida em C# (.NET) para o gerenciamento de uma locadora de jogos, estruturada com separação de responsabilidades em camadas.

## 🏗️ Arquitetura do Projeto

O sistema foi organizado seguindo boas práticas de divisão de camadas:
- **LocaGames API:** Camada de apresentação, controllers e endpoints da aplicação.
- **LocaGames API.Domain:** Entidades, regras de negócio e interfaces centrais.
- **LocaGames API.Infra:** Acesso a dados, repositórios e integração com banco de dados.
- **Database:** Scripts e estruturas relacionadas ao banco de dados.

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C#
- **Framework:** .NET / ASP.NET Core
- **Banco de Dados:** SQL

## 🚀 Como Executar o Projeto

1. Faça o download ou clone este repositório na sua máquina.
2. Abra o arquivo `.sln` no **Visual Studio**.
3. Compile e execute o projeto pressionando `F5`.
